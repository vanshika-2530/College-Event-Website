# Project JS

A simple web project built with HTML, CSS, and JavaScript.

---

## 📂 File Order

Here’s the preferred order of files in this repository:

1. **index.html** – Main homepage
2. **script.js** - js of index page and saved page
3. **events.html** – All events listing
4. **tech.html** - Tech events page
5. **academic.html** – Academic events page
6. **cultural.html** – Cultural events page
7. **creative.html** – Creative events page
8. **saved.html** – Saved events
9. **register.html** – Registration form
10. **register.js** - js of register page and events pages
11. **projnp.html** – Project details page
12. **projnp.js** - js of profile page
13. **style.css** – Main stylesheet 
14. **about.html** – About section
15. **contact.html** - Contact section
